# Advent of Code 2025 via MoonBit

This repo contains my attempt at Advent of Code 2025
(<https://adventofcode.com/2025>)
trying to use MoonBit (<https://www.moonbitlang.com/>)

## Prerequisites

- Requires moon 0.1.20251202 (or later)
- Requires moonc v0.6.33 (or later)

## Running

```console
$ moon run ./src/cmd/day01
```
